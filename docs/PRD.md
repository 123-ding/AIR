## 1. 项目概述

### 1.1 背景

随着低空经济的快速发展，无人机在农业植保、物流配送、航拍测绘、巡检安防、应急救援等领域的应用日益广泛。然而，需求方（客户）与供给方（飞手/机队）之间缺少高效的对接平台，存在以下痛点：

- **客户侧**：找不到合适的无人机服务提供商，报价不透明，服务质量参差不齐。
- **飞手/机队侧**：获客渠道单一，接单效率低，空闲运力无法有效利用。
- **管理侧**：订单调度靠人工，缺少实时监控，无法形成数据沉淀。

### 1.2 产品定位

构建一个 **无人机服务的接单派单平台**，连接需求方与供给方，通过 **智能派单引擎** 实现高效的供需匹配与任务调度，实现订单全生命周期管理。

### 1.3 核心价值

| 价值维度 | 描述 |
|---------|------|
| 🎯 高效匹配 | 基于位置、能力、评分等多维因素智能派单 |
| 📍 实时可视 | 无人机位置、任务进度、订单状态实时可追踪 |
| 💰 交易闭环 | 下单 → 执行 → 验收 → 结算的全链路闭环 |
| 📊 数据驱动 | 运营数据沉淀，驱动平台持续优化 |
| 🔒 安全可控 | 飞手资质审核、飞行合规校验、保险机制 |

## 2. 目标用户与角色

| 角色 | 说明 | 关键诉求 |
|------|------|---------|
| **客户 (Customer)** | 有无人机服务需求的个人/企业 | 快速下单、透明报价、实时追踪、服务可靠 |
| **飞手 (Pilot)** | 持证无人机操作员，个人接单 | 高效接单、合理派单、收入透明 |
| **机队管理员 (Fleet Manager)** | 管理多架无人机和多名飞手的团队负责人 | 统一管理旗下飞手与设备、批量接单 |
| **平台运营 (Operator)** | 平台运营管理人员 | 监控订单、处理纠纷、管理用户、分析数据 |
| **系统管理员 (Admin)** | 系统最高权限管理者 | 系统配置、权限管理、安全审计 |

## 3. 核心业务流程

```
┌─────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌─────────┐
│  客户    │    │  调度中心 │    │  飞手/   │    │  任务    │    │  结算   │
│  下单    │───▶│  智能派单 │───▶│  机队接单 │───▶│  执行    │───▶│  评价   │
└─────────┘    └──────────┘    └──────────┘    └──────────┘    └─────────┘
     │              │               │               │               │
     ▼              ▼               ▼               ▼               ▼
  需求发布      匹配算法        确认/拒绝       实时监控        费用结算
  服务选择      优先级排序      协商沟通        进度更新        双向评价
  预估报价      通知推送        出发准备        异常处理        信用更新
```

### 3.1 主流程说明

1. **客户发布需求**：选择服务类型、填写任务详情（地点、时间、面积/距离等）、获得预估报价、确认下单。
2. **智能派单**：系统根据算法自动匹配最优飞手/机队，发送接单通知；支持抢单模式或指派模式。
3. **飞手接单**：飞手收到通知后查看任务详情，确认接单或拒绝（系统自动轮转下一位）。
4. **任务执行**：飞手到达现场 → 开始作业 → 实时上报进度 → 完成作业 → 提交成果。
5. **验收结算**：客户确认验收 → 系统自动结算 → 费用分账（平台 + 飞手）→ 双方互评。

## 4. 功能模块详细设计

### 4.1 用户端（下单）

#### 4.1.1 注册与认证
- 手机号/邮箱注册登录
- 企业用户实名认证（营业执照上传）
- 个人用户实名认证（身份证验证）

#### 4.1.2 服务浏览与选择
- **服务类目**：
  - 🌾 农业植保（喷洒、播种、施肥）
  - 📦 物流配送（短途运输）
  - 📸 航拍摄影（婚礼、活动、地产）
  - 🗺️ 测绘建模（地形测绘、3D建模）
  - 🔍 巡检安防（电力巡检、管道巡检、安防巡逻）
  - 🆘 应急救援（搜索救援、物资投送）
  - 🎯 其他定制服务
- 服务详情页（服务说明、价格参考、案例展示）
- 附近可用飞手/机队列表

#### 4.1.3 智能下单
- 地图选点/画区域（标记作业范围）
- 填写任务详情表单：
  - 服务类型
  - 作业地点（支持地图定位）
  - 预约时间（立即/预约）
  - 作业面积/距离/时长
  - 特殊要求（备注）
  - 附件上传（参考图片/文件）
- **智能报价**：根据服务类型 × 面积/距离 × 难度系数 自动估价
- 确认下单并支付（预付/到付）

#### 4.1.4 订单追踪
- 订单状态实时更新
- 飞手位置实时追踪（地图展示）
- 作业进度查看
- 在线沟通（IM 聊天）

### 4.2 调度中心（派单引擎）

#### 4.2.1 派单模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **智能派单** | 系统根据算法自动指派最优飞手 | 标准化服务、即时订单 |
| **抢单模式** | 将订单推送给符合条件的飞手，先抢先得 | 简单任务、运力充足区域 |
| **手动指派** | 运营人员手动分配飞手 | 特殊任务、VIP客户、复杂需求 |
| **定向邀请** | 客户指定飞手/机队 | 回头客、长期合作 |

#### 4.2.2 智能匹配算法 — 匹配因子

```
匹配得分 = W1 × 距离因子 + W2 × 能力匹配度 + W3 × 信用评分 
         + W4 × 历史完成率 + W5 × 响应速度 + W6 × 设备匹配度
         + W7 × 价格因子 + W8 × 时间可用性
```

| 因子 | 说明 | 权重建议 |
|------|------|---------|
| 距离因子 | 飞手当前位置与作业地点的距离 | 25% |
| 能力匹配度 | 飞手持有的资质证书与服务类型匹配 | 20% |
| 信用评分 | 飞手综合信用分 | 15% |
| 历史完成率 | 历史订单完成率 | 15% |
| 响应速度 | 平均接单响应时间 | 10% |
| 设备匹配度 | 飞手拥有的无人机型号是否满足任务需求 | 5% |
| 价格因子 | 飞手报价与客户预算的匹配度 | 5% |
| 时间可用性 | 飞手当前是否空闲 | 5% |

#### 4.2.3 派单流转规则
- 订单创建后 **5秒内** 完成首次匹配
- 飞手 **3分钟内** 未响应 → 自动轮转给下一位
- 最多轮转 **5轮** → 进入抢单池
- 抢单池 **30分钟** 无人接单 → 通知运营人工介入
- 支持取消派单、重新派单

### 4.3 飞手/机队端（接单）

#### 4.3.1 飞手入驻与认证
- 基本信息注册
- **资质认证**：
  - 无人机驾驶执照上传（CAAC/AOPA）
  - 身份证实名认证
  - 飞行经验填写
  - 服务区域设置
  - 可服务类型勾选
- 审核流程（平台人工/自动审核）

#### 4.3.2 接单管理
- 订单推送通知（声音 + 震动 + 弹窗）
- 订单详情查看（任务类型、地点、时间、报价）
- 一键接单/拒绝（可填写拒单原因）
- 接单后导航到作业地点
- 当日/未来排期日历视图

#### 4.3.3 机队管理（Fleet Manager）
- 添加/管理旗下飞手
- 统一接单后内部分配
- 设备统一管理
- 收入汇总与分配

### 4.4 无人机管理

#### 4.4.1 设备注册
- 无人机型号、序列号
- 购买日期、保修状态
- 所属飞手/机队
- 适用服务类型标签

#### 4.4.2 设备状态管理

| 状态 | 说明 |
|------|------|
| 🟢 空闲 (Idle) | 可接受新任务 |
| 🔵 任务中 (In Mission) | 正在执行任务 |
| 🟡 充电中 (Charging) | 正在充电 |
| 🔴 维修中 (Maintenance) | 维修保养中，不可用 |
| ⚫ 停用 (Disabled) | 已停用 |

#### 4.4.3 设备维护记录
- 飞行时长统计
- 维护保养记录
- 故障报修记录
- 电池循环次数

### 4.5 订单管理

#### 4.5.1 订单状态机

```
[待支付] ──▶ [已支付/待派单] ──▶ [已派单/待接单] ──▶ [已接单]
                                        │                    │
                                   [无人接单]           [飞手出发]
                                        │                    │
                                   [运营介入]           [到达现场]
                                                            │
                                                       [作业中]
                                                            │
                                                    [作业完成/待验收]
                                                            │
                                                  ┌─────────┴─────────┐
                                              [验收通过]          [验收不通过]
                                                  │                    │
                                             [已结算]            [协商/重做]
                                                  │
                                             [已评价]
                                                  │
                                             [已完成]
```

#### 4.5.2 订单操作
- 创建订单
- 取消订单（规则：作业前免费取消，飞手出发后收取一定费用）
- 修改订单（仅限待派单状态）
- 订单详情查看
- 订单历史记录
- 订单导出（CSV/Excel）

### 4.6 任务执行与监控

#### 4.6.1 飞手端任务操作
- 确认出发 → 到达现场 → 开始作业 → 暂停/继续 → 完成作业
- 上传作业成果（照片、视频、数据文件）
- 异常上报（天气不宜、设备故障、客户原因等）
- 飞行日志自动记录

#### 4.6.2 实时监控大屏（运营端）
- 地图视图：所有在执行任务的无人机实时位置
- 订单看板：各状态订单数量统计
- 告警中心：异常订单实时告警
- 区域热力图：订单密度分布

### 4.7 结算与支付

#### 4.7.1 支付方式
- 在线支付（微信/支付宝/银行卡）
- 企业账期（月结/季结）
- 钱包余额支付

#### 4.7.2 结算规则
- 客户验收通过后自动结算
- 超时未验收（48小时）自动确认
- **平台抽佣**：可配置比例（默认 15%）
- 飞手提现（T+1 到账）
- 退款流程（全额退款 / 部分退款）

#### 4.7.3 财务管理
- 飞手收入明细
- 平台流水记录
- 发票管理
- 对账报表

### 4.8 评价与信用体系

#### 4.8.1 评价机制
- **客户评飞手**：服务质量 ⭐、专业程度 ⭐、响应速度 ⭐、沟通态度 ⭐、文字评价
- **飞手评客户**：配合程度 ⭐、现场条件 ⭐、文字评价
- 评价时限：订单完成后 7 天内
- 评价展示：公开（脱敏）

#### 4.8.2 信用体系
- **信用分**：初始 100 分
  - 好评 +2 / 差评 -5
  - 按时完成 +1 / 超时 -3
  - 取消订单 -10
  - 被投诉（核实后） -20
- **信用等级**：

| 等级 | 分数范围 | 权益 |
|------|---------|------|
| 🥇 金牌飞手 | 90-100 | 优先派单、低抽佣、专属标识 |
| 🥈 银牌飞手 | 70-89 | 正常派单 |
| 🥉 铜牌飞手 | 50-69 | 降低派单优先级 |
| ⚠️ 警告 | 30-49 | 限制接单 |
| 🚫 封禁 | <30 | 暂停服务 |

## 5. 非功能性需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 接口响应时间 | P95 < 200ms |
| 派单响应时间 | < 5s 完成匹配 |
| 地图加载时间 | < 2s |
| 并发用户数 | 支持 10,000+ 同时在线 |
| 消息推送延迟 | < 1s |

### 5.2 可用性
- 系统可用性 ≥ 99.9%
- 支持服务降级与熔断
- 数据备份：每日全量 + 实时增量

### 5.3 安全性
- 用户数据加密存储（AES-256）
- HTTPS 全链路加密
- API 接口鉴权（JWT Token）
- 敏感操作二次验证
- 日志审计（操作日志保留 180 天）
- RBAC 权限控制

### 5.4 兼容性
- Web端：Chrome、Firefox、Safari、Edge 最新两个大版本
- 移动端：iOS 14+、Android 10+
- 响应式设计，适配主流分辨率

### 6.1 技术选型建议

| 层级 | 技术 | 说明 |

## 10. 风险与应对

| 风险 | 影响 | 概率 | 应对策略 |
|------|------|------|---------|
| 飞行合规政策变化 | 高 | 中 | 保持政策跟踪，预留合规扩展接口 |
| 初期飞手供给不足 | 高 | 高 | 种子用户补贴，合作引入机队 |
| 无人机飞行事故 | 高 | 低 | 接入保险、要求飞手资质审核、飞行前检查清单 |
| 恶劣天气影响作业 | 中 | 中 | 集成天气 API，自动预警，支持改期 |
| 支付纠纷 | 中 | 中 | 资金托管、验收机制、客服介入流程 |
| 系统高并发压力 | 中 | 中 | 微服务拆分、Redis 缓存、MQ 削峰 |
| 用户数据泄露 | 高 | 低 | 加密存储、权限控制、安全审计 |
